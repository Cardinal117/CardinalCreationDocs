## Itemization Goal

Gear should change how players behave, fight, travel, and interact socially. It should not only increase numbers.

## Spellstones

Spellstones are modular magical ability stones found, traded, purchased, won, crafted, or earned.

| Source | Role |
|---|---|
| loot | exploration and combat reward |
| trade | player economy |
| merchants | progression access |
| tournaments | prestige |
| quests | lore-tied unlock |
| ruins | ancient series |
| bosses | rare pieces |

## Class-Specific Interpretation

The same stone can reveal different skill visions by discipline:

| Stone | Mage | Warrior | Archer |
|---|---|---|---|
| Storm | lightning ritual | lightning slash | chain arrow recall |
| Blood | lifedrain spell | lifesteal cut | bleeding return path |
| Earth | stone barrier | hammer rupture | tunneling arrow |
| Sun | holy beam | radiant blade | flare volley |

## Dwarven Crafting

The dwarf realm is the advanced crafting center.

Inputs:

- weapon blueprint.
- core material.
- edge/head material.
- grip/shaft material.
- rune channel.
- socket design.
- blacksmith skill.
- rare catalyst.

Weapon attributes:

| Attribute | Effect |
|---|---|
| length | reach and handling |
| weight | stamina, impact, speed |
| balance | recovery and stance stability |
| material | durability and compatibility |
| socket count | spellstone capacity |
| socket alignment | supported series/elements |
| rune channeling | cooldown, Vitae cost, charge speed |

Important rule: more slots should not automatically mean best for every build. Socket alignment and material compatibility should matter.
