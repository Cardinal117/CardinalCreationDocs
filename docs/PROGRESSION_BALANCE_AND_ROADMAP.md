## Progression Tracks

| Track | Progression |
|---|---|
| character level | survivability, stamina, Vitae, unlocks |
| weapon mastery | stance slots, chains, cancels |
| magic study | pages, schools, rituals, incantations |
| ranged mastery | quivers, curve shots, scout vision, recall variants |
| crafting access | blueprints, forge permissions, material knowledge |
| reputation | faction access, prices, guard behavior |
| artifact corruption | demon eye power and curse management |

## Player Stages

| Stage | Features |
|---|---|
| early | basic weapon, four stances, early glove, simple grimoire, clear settlement rules |
| mid | first spellstones, first socketed weapon, first advanced stance, dwarf access |
| late | legendary crafting, full series, advanced demon eyes, world bosses, master arts |

## Balance Principles

| Principle | Reason |
|---|---|
| physical skill matters | VR mastery should use the player's body |
| build choices matter | gear should change playstyle |
| readable tells matter | other players need to understand powerful effects |
| voice is optional | incantations are fun, not mandatory |
| stance recognition is forgiving | bodies and tracking vary |
| ranged paths are readable | curve, arc, tunnel, and recall need previews |
| party roles help but do not hard-lock | solo should remain possible |
| curses are tempting | downsides need worthwhile power |

## Prototype Roadmap

### Phase 0

- validate UE 5.7 VR performance.
- validate Nanite, foliage, World Partition, and HLOD.
- validate SpacetimeDB Unreal integration.

### Phase 1

- VR pawn.
- physical weapon pickup.
- grimoire pickup.
- early glove with health and Vitae vials.
- cardinal familiar UI entry.

### Phase 2

- four sword stances.
- combat spell ring.
- bow recall crystal.
- curved-shot range vision.
- high-arc preview.
- Eagle Eye scout lens.

### Phase 3

- SpacetimeDB character identity.
- nearby player subscription.
- remote avatar smoothing.
- cell subscription switching.

### Phase 4

- 8 km or 16 km test world.
- HLOD.
- far proxy layer.
- Nanite foliage test.
- simulated load tests.

### Phase 5

- weapon tiers.
- spellstones.
- socketed weapon.
- one three-stone series.
- dwarven crafting test.
- one demon eye with social consequences.
